# Screenshots

Theme screenshots referenced by the top-level `README.md`.

Expected files:

- `preview.png` — the main hero shot shown at the top of the README.
- Optional extras, e.g. `typescript.png`, `css.png`, referenced from the Preview section.

Tips:
- Use PNG. Capturing at 2x (retina) is fine; renderers scale it down and it stays crisp.
- Keep individual files small (ideally a few hundred KB) so the packaged `.vsix` stays lean.
- Show real code in languages the theme highlights well.
